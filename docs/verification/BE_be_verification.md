## 6. На что обратить внимание в этой роли

- Backend API разворачивается в 2 репликах за Nginx; TLS завершается на Nginx, внутри кластера порт 8000 (HTTP).
- Backend API ставит задачи разметки и публикует их по схеме `ReviewsLabelingTaskV1`; читать `cases.events` он не должен.
- Проверка токена идёт у `bank_iam` по OIDC (шаг 3); отчёты уходят в `reporting_system` (связь есть в L0 и на развёртывании, в динамике её нет).
- REST-вызовы в динамике (`POST /feedback/batches`, `GET /cases/{case_id}`, `PATCH /cases/{case_id}/status`, `GET /cases`) должны совпадать с `docs/packages/contracts/openapi/api.v1.yaml`.
