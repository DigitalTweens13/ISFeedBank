## 5. Эталон: связи на диаграмме развёртывания

| Инициатор | Получатель | Описание | Протокол, порт, шифрование |

| Backend API | Брокер сообщений | Ставит задачи разметки для загруженного пакета отзывов | AMQP, TCP 5671, TLS |
| Воркер разметки | Брокер сообщений | Забирает задачи разметки из reviews.labeling и публикует события в cases.events | AMQP, TCP 5671, TLS |

## 6. На что обратить внимание в этой роли

- Брокер — кластер RabbitMQ из 3 узлов, очереди типа quorum; порт клиентов 5671 (AMQP + TLS), порт управления 15672 доступен только из сети администрирования.
- Очередей две: `reviews.labeling` (публикуют Backend API и воркер фоновых задач, читает воркер разметки) и `cases.events` (публикует воркер разметки, читает воркер фоновых задач); у каждой есть очередь `.dlq` для сообщений после трёх неудачных попыток.
- Брокер сам ничего не вызывает: все стрелки в динамике идут от клиентов брокера к нему (правило «стрелка от инициатора соединения»).
- Права клиентов на очереди должны соответствовать этим связям (например, воркер разметки не публикует в `reviews.labeling`).
